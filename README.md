# Tugas HTML Semantic

Repository ini berisi kode pembelajaran dan praktik mengenai **Semantic HTML**. Tugas ini dikerjakan berdasarkan materi dan instruksi yang diberikan oleh guru saya.

## Deskripsi

Proyek ini bertujuan untuk memahami dan mengimplementasikan tag-tag semantik dasar pada HTML5 (seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`). 

Penggunaan tag semantik membuat struktur halaman web menjadi lebih rapi dan bermakna. Hal ini tidak hanya mempermudah *developer* dalam membaca kode, tetapi juga membantu mesin pencari (SEO) memahami konten website, serta meningkatkan aksesibilitas bagi pengguna dengan kebutuhan khusus (misalnya yang menggunakan *screen reader*).

## Struktur Kode

Kode dalam repository ini difokuskan pada:
- Penggunaan elemen HTML yang tepat sesuai dengan fungsinya.
- Menghindari penggunaan `<div>` yang berlebihan (*div soup*) jika ada tag semantik yang lebih cocok.

## Teknologi yang Digunakan

*   **HTML5**

## Cara Menjalankan

Karena ini adalah file HTML statis, Anda hanya perlu membukanya langsung di browser
